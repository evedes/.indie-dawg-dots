## Documentation & notes

`~/Nextcloud/Multiverse` is Edo's global markdown knowledge repo — a flat collection of `.md` notes (Obsidian-style: frontmatter with `id`/`created`/`updated`/`aliases`/`tags`, an `# UPPERCASE TITLE` heading, and `[[wiki-links]]`) used to keep durable information across all projects.

When writing a persistent/reference doc or knowledge note (setup guides, how-tos, research, decisions), **default to `~/Nextcloud/Multiverse`** — write it there without asking. Edo will say so explicitly when a note belongs somewhere else. Match the existing note format, use a kebab-case filename without project prefixes, and keep one topic per file. Repo-specific docs (e.g. a project's `CLAUDE.md`, READMEs) stay in their repo.

Do **not** put Edo's knowledge notes in Claude's own memory store.
